# Мой первый проект на Go 🚀

Простая и надежная консольная утилита на Go, которая запрашивает у пользователя текст и сохраняет его в файл `hello.txt` на Рабочем столе.

## Особенности
- Логирует все действия и ошибки в файл `server.log`.
- Безопасно сохраняет данные на диск с проверкой ошибок ввода-вывода.

## Как запустить
bash go run main.go
